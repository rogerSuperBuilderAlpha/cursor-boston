## Project Idea: AI Athlete Performance Predictor

A machine learning tool that predicts athlete performance metrics
using historical game data and injury history, built with Python,
FastAPI, and a Streamlit dashboard.

## Tech Stack
- Python, scikit-learn / PyTorch
- FastAPI backend
- Streamlit frontend
- Sports reference data APIs
